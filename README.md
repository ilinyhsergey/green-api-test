# green-api-test

## Требования

- [Node.js](https://nodejs.org/) версии 20.19+ или 22.12+
- npm (устанавливается вместе с Node.js)

## Установка зависимостей

```bash
npm i
```

## Запуск для разработки

```bash
npm run dev
```

Приложение откроется по адресу, который выведет Vite (по умолчанию http://localhost:5173). Изменения в коде применяются без перезагрузки страницы.

## Запуск для просмотра

Собрать проект и запустить локальный сервер с готовой сборкой:

```bash
npm run build
npm run preview
```

Приложение будет доступно по адресу, который выведет Vite (по умолчанию http://localhost:4173).
